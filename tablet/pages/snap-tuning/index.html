Snap tuning

How close things must be before the drawing view snaps them together. A change is saved at once, in this browser, and every drawing view of this browser uses it from the next pen stroke: no reload. Move a slider, then drag a line end in the drawing view below. main menu

Distances

world = the document's units: on the skull pages 0.01 world is 1 mm, and a line of default width is 0.005 world across. pixels = on screen, whatever the zoom. A yellow value differs from the default.
