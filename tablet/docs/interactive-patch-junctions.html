How a patch finds its junctions and corners

A patch stores only a list of lines. The loop, its junctions and its corners are re-derived every frame in tablet/src/patch.ts (stroke_junctions, chain_into_loop, cut_loop_into_sides). Both demos below run a port of that code. Nothing looks at angles or positions: it is all vertex ids and smooth knots.

1 · Chaining the lines into a loop

Each line offers junctions: its two endpoint vertices, then every vertex pinned on it. The search starts on the first line of the patch and repeatedly looks for an unused line that has a junction with the same vertex id as the current end of the loop. Step through it:

    2 · Which junctions are corners

    Walk the finished loop. At each junction, ask one question: is there a smooth knot between the two lines meeting here? Knot = the loop passes through and both lines belong to the same side. No knot = corner. Click a junction to toggle its knot (the smooth button in the app).

    corner (no knot) smooth knot (not a corner)  ·  each colour = one side

    Untick "draw knotted junctions smoothly": the shape becomes a plain polygon and the answer does not change. The side count depends only on the knots, never on how sharp a junction looks.
